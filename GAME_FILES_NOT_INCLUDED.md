# Game files

This release does not supply the NBA 2K17 game executable, game DLLs, Steam files, DRM-bypass files, original roster saves, or full game archive/container files.

The app uses its own saved card data, field definitions, reusable player templates, artwork, and Studio resources. Injection works with a roster the user has already loaded in their own NBA 2K17 installation.

Modded face/cyberface and in-game portrait assets must be obtained and installed separately. Saved card templates do not contain those assets or install them into the game.
