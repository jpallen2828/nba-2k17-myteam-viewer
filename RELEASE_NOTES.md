# NBA 2K17 MyTEAM v1.0.0

Initial GitHub release of the combined MyTEAM archive, team builder, and Card Studio.

- Includes 2,130 available cards and original PNG artwork with no image recompression.
- Includes recent Pascal Siakam, Jaylen Brown, Damian Lillard, Jimmy Butler, Joel Embiid, Nikola Jokic, Jamal Murray, and Andre Iguodala custom cards.
- Supports reusable player templates, signatures, shoes/gear, accessories, handedness, commentary identity fields, and custom-card injection data.
- Includes Create a Team, Random Team, and Draft a Team, plus custom-card filters and management.
- Uses selected team/slot destination addressing and automatic linked-storage ownership checks, with preview/readback/undo protection.
- Adds Steam roster-folder suggestions while retaining manual folder selection.
- Adds a migration helper for personal data from older portable installations.
- Provides source code, build resources, checksums, and screenshots.

Compatibility remains limited to verified NBA 2K17 executable/roster layouts. External modded face and portrait assets are not included. This release does not claim new in-game visual or audio verification beyond the existing verified mappings.
