# NBA 2K17 MyTEAM v1.2.0

Updated October 10, 2026.

- Adds Super Budget as the fourth draft setting, with separate starter, bench, and deep-bench odds.
- Ends Super Budget drafts with a Sapphire round: Pink Diamond 0.001%, Diamond 0.01%, Amethyst 0.1%, Ruby 1%, and Sapphire 98.889%.
- Hover tooltips show plain decimal percentages, including extremely rare tiers.
- Preserves all other draft rules, saved packs, custom-card filtering, badge counters, and Open 3PT ratings.
- Includes 2,181 available cards, including all currently saved cards, original artwork, editable custom-card packages, and reusable injection data. Card artwork is not recompressed.
- Includes the Domantas Sabonis face ID 1 override for future injections, along with previous player-data corrections.
- Updates source code, regression checks, screenshots, matching build resources, and SHA-256 checksums.

Download **NBA.2K17.MyTEAM.zip**, extract the entire archive, and run **2K17 MyTEAM.exe**. Keep the included `.project` folder beside the EXE. The build-resources download is optional and only needed to build from source.

For an existing installation, follow [UPDATING.md](UPDATING.md). Extract into a new folder and preserve your previous installation until your personal cards and lineups have been checked.

Compatibility remains limited to verified NBA 2K17 executable/roster layouts. External modded face and portrait assets are not included.
